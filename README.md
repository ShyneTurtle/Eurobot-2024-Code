## Convention de mise en forme du code
- Langue: Code en anglais et commentaires en français
- Indentation: 2 ou 4 espaces
- Variables: minuscule et mots séparés par des underscore (`nom_de_variable`)
- Fonctions: première lettre en minuscule, lettre de chaque mot en majuscule (`nomDeFonction`)
- Classes: lettre de chaque mot en majuscule (`NomDeClasse`)
- Pointeurs: astérisque collée au type (`int* pointeur`)
- Commentaires: 1 espace après les //, et un avant si en fin de ligne

(`// Commentaire sur une ligne` et `int x = 0; // Commentaire de fin de ligne`)
- Documentation: Utiliser la syntaxe JSDoc pour documenter tout le code (fonctions, classes, todo...)

**/!\ Privilégiez la clareté des noms, peut importe leur longueur (pareil pour les commentaires).**
